Java Introduction

Java is a class-based, object-oriented programming language designed to have as few implementation dependencies as possible. It powers Android apps, enterprise backends, and billions of devices worldwide.

What is Java?

Java was created by James Gosling at Sun Microsystems, released in 1995 and is owned by Oracle. It follows the principle "Write Once, Run Anywhere" — compiled Java code runs on any platform that has a Java Virtual Machine (JVM).

  • Platform-independent — runs on Windows, Mac, Linux via the JVM
  • Object-Oriented — everything is organized into classes and objects
  • Strongly typed — every variable must have a declared type
  • Memory-managed — Garbage Collector handles memory automatically
📌 Note: Java is different from JavaScript. They share a name but are entirely different languages with different purposes.

JDK vs JRE vs JVM

TermStands ForWhat it does
JVMJava Virtual MachineRuns compiled Java bytecode
JREJava Runtime EnvironmentJVM + standard class libraries
JDKJava Development KitJRE + compiler (javac) + dev tools
✅ Tip: To write and compile Java programs, you need the JDK. Follow the instructions below to install it on your system.

How to Install Java to get started

Some PCs may already have Java installed. To check if you have Java installed on a Windows PC, search in the start bar for java or type the following in Command Prompt(cmd.exe):

Command Prompt 
C:\Users\Your Name>java -version
▶ Output: java version "17.0.1" 2021-10-19 LTS

If you see a version number, you're good to go! If not, download the JDK from Oracle's official site or use OpenJDK. Follow the installation instructions for your operating system.

Your First Java Program

Every Java program starts with a class and a main method. Here's the classic Hello World:

Main.java 
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
▶ Output: Hello, World!

Breaking it down

  • public class Main — declares a class named Main. The filename must match: Main.java.
  • public static void main(String[] args) — the entry point. Every Java program starts here.
  • System.out.println() — prints text to the console followed by a newline.

How to Compile and Run

Once you have the JDK installed, open a terminal and run:

Terminal 
# Step 1: Compile
javac Main.java

# Step 2: Run
java Main
▶ Output: Hello, World!
⚠️ Important: The class name and filename must match exactly, including capitalization. Main.java must contain public class Main.

Java Comments

Comments are ignored by the compiler. Use them to explain your code:

Comments.java 
public class Comments {
    public static void main(String[] args) {
        // This is a single-line comment

        /* This is a
           multi-line comment */

        System.out.println("Comments don't affect output");
    }
}
▶ Output: Comments don't affect output
