Java Syntax

In the previous chapter, Introduction, we created a Java file called Main.java, and we use the following code to print "Hello, World!" to the console.

Example:

Main.java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
▶ Output: Hello, World!

Explaination

Every line of code that runs in Java must be inside a class. The class name should always start with an uppercase first letter. In our example above we named the class Main. (Take note that java is case-sensitive. MyClass and myclass would be treated as two different names).

The name of the Java file must match the class name, so since we called our class Main, the file must be saved as Main.Java. This is because Java used the class name to find and run your code. if the name don't match, then Java will give an error and the program wont run.

When saving the file, save it using the class name and add java to the end of the filename.

The main Method

The main() method is the entry point of any Java program. It is where the program starts running:

Main.java
    public static void main(String[] args)

Any code placed inside the main() method will be executed.

System.out.println()

Inside the main() method, you can use the println() method to print text to the screen:

Example:

Main.java
    public static void main(String[] args) {
        System.out.println("Hello World!");
    }

Think of System.out.println() as a single command that means "send this text to the screen".

Note: The curly braces {} mark the beginning and end of a block of code.

Here's what eachy part means:

  • System — a built-in Java class that provides access to system resources.
  • out — a static member of the System class that represents the standard "output" stream (the console).
  • println() — a method that prints the specified text to the console, followed by a newline, short for "printline".

    • Always remember that each Java statement must end with a semicolon (;).
